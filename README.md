# SKMamba

Official implementation of the MICCAI 2026 paper **"Structure-aware Knowledge-guided Heterogeneous Mamba for Zygomaticomaxillary Suture Assessment"**.

This repository is for automated zygomaticomaxillary suture (ZMS) maturation staging from CBCT images.

## Status

The code is currently being organized and will be released soon.

The ZMS dataset will also be released after further preparation. The dataset download link and usage instructions will be provided in this repository.

## Overview

SKMamba is a structure-aware and knowledge-guided Mamba-based framework for ZMS maturation assessment. It combines structural pre-training with anatomical semantic guidance to improve fine-grained staging of ZMS maturation from CBCT regions of interest.

## Dataset

The ZMS dataset contains professionally annotated CBCT regions of interest for five-stage ZMS maturation assessment.

The dataset will be made available via Google Drive. Please check this repository for future updates.
